# Operations Knowledge

This directory indexes operational reasoning and runbook entry points. Detailed
procedures remain authoritative in repository skills and runbooks.

Primary entry points:

- [`skills/deploy/SKILL.md`](../../skills/deploy/SKILL.md) for production
  deployment and rollback gates.
- [`skills/memory/SKILL.md`](../../skills/memory/SKILL.md) for SQLite and Qdrant
  maintenance.
- [`skills/telegram/SKILL.md`](../../skills/telegram/SKILL.md) for Telegram
  runtime diagnosis.
- [`docs/runbooks/`](../../docs/runbooks/) for operation-specific procedures.

An operations note must never substitute a summary for the current executable
gate, production evidence, or explicit mutation authority.
