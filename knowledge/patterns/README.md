# Engineering Patterns

This directory indexes reusable implementation and validation patterns, such as
tenant-scoped queries, derived-index rehydration, immutable release identity,
and fail-closed evidence handling.

Patterns must preserve [`docs/HERMES_INVARIANTS.md`](../../docs/HERMES_INVARIANTS.md)
and link to focused tests or authoritative skills. Do not turn a local example
into a repository-wide rule unless the invariant or contract supports it.
